feedme transforme n'importe quelle page web en un flux RSS 2.0, Atom 1.0, ou JSON Feed 1.1, y compris pour les sites qui ne publient pas leur propre flux.
Les options sont intégrées à l'URL du flux, donc un flux correspond à une URL que vous pouvez éditer ou partager directement. 
Il est également possible de combiner plusieurs flux en une seule URL.
